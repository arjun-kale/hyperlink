# linux/

Rust + GTK4/Libadwaita host application. Owns the QUIC endpoint, GStreamer decode pipeline, input capture, the FUSE virtual mount, and the Libadwaita UI.

**Status:** Phase 1 complete. Phases 2-11 implemented in code and unit-tested; hardware validation against the physical Definition-of-Done in each phase is still pending. See `docs/SYSTEM_DESIGN.md` and `CHANGELOG.md` for the current per-phase status.
